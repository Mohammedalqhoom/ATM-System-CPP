# ATM System — C++

A console-based ATM System developed using C++ to apply core programming concepts through a practical financial application.

## 📌 Project Overview

The ATM System simulates the basic operations of an Automated Teller Machine (ATM).

The system allows users to authenticate using their account number and PIN, perform withdrawals and deposits, check their balance, and safely update account data using file-based persistence.

The project was developed to practice structured programming, problem solving, file handling, input validation, modular programming, and reusable helper libraries.

## ✨ Features

- 🔐 User authentication using account number and PIN
- 💵 Quick withdrawal with predefined amounts
- 💰 Normal withdrawal with custom amounts
- ➕ Deposit money into an account
- 💳 Balance checking
- 🔄 Update account balance
- 💾 File-based data persistence
- ✅ Input validation
- 🚪 Secure logout
- 🧩 Reusable helper libraries

## 📂 Data Storage

The system uses text files to store and update account information.

Account data includes:

- Account Number
- PIN
- Client Name
- Phone Number
- Balance

The system reads account information from files, processes transactions, updates balances, and saves the changes back to the files.

## 🔄 ATM Operations

### Login

Users authenticate using:

- Account Number
- PIN

After successful authentication, the user can access the ATM menu.

### Quick Withdraw

The system provides predefined withdrawal amounts such as:

- 20
- 50
- 100
- 200
- 400
- 600
- 800
- 1000

### Normal Withdraw

Users can enter a custom withdrawal amount.

The system validates the amount before processing the transaction.

### Deposit

Users can enter an amount to deposit into their account.

The account balance is updated and saved to the data file.

### Check Balance

Users can view their current account balance.

## 📚 Helper Libraries

The project uses reusable helper libraries to separate common functionality, including:

- `MyLibMath.h`
- `MyLibFile.h`
- `MyLibString.h`
- `MyLiSeting.h`

These libraries provide reusable functionality for mathematical operations, file handling, string processing, and system-related utilities.
